# Подготовить инженерное решение

[Каталог · Планирование](../../docs/skills.md#планирование)

Цитата не включает навык. Вне faust-mode применяй только явно вызванные навыки.

Сформулируй вопрос, который мешает реализации. Установи потребителей, среду и
поток данных по рабочему примеру. Сначала проверь возможности проекта и платформы.

Выбери источник истины, допустимые состояния, владельцев записи и освобождения
ресурсов. Валидируй внешний ввод на границе доверия по одной схеме.
Для существенных вариантов покажи типичный вызов, порядок действий, ошибки,
стоимость и совместимость. Выбирай решение, которое потребитель сможет проверить.
Если несколько флагов приходится синхронно менять, сравни текущую форму
с моделью, где противоречивое сочетание невозможно. Проведи один и тот же
сценарий через оба интерфейса. Сохрани простую форму, когда все её состояния
допустимы и у решения один владелец.

Если чтение не разрешает вопрос, задай результат, который изменит выбор,
и проверь его разрешённым прототипом. Проверь путь реального клиента API
или пользователя UI. Передай решение, причину, порядок внедрения и критерий
готовности. Для конкуренции учти [state](../state/SKILL.md), для перехода
между версиями — [migrate](../migrate/SKILL.md).
