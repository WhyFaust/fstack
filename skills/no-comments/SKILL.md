# Код без лишних комментариев

По умолчанию избегай пояснений строк, подписей шагов, разделителей, заметок
о правке, закомментированного кода и отладочных фрагментов.

Покажи назначение именами, структурой, данными и контрактами. Выделяй
содержательные операции без лишней абстракции. Исправляй неясный код,
ошибки и инварианты. Обоснование и историю оставляй в документации или PR.

Для невыразимого кодом внешнего ограничения оставь краткую причину с
проверяемым основанием, если оно доступно. Сохраняй лицензии, авторство,
shebang, кодировку, директивы инструментов и требуемые документы API.
В docstring описывай контракт. Подавление диагностики обоснуй.

Убирай устаревшее только в затронутом участке. Сохрани действующие ограничения
и явно требуемые комментарии. Перед удалением проверь роль строки в сборке,
генерации и анализе.

Просмотри diff с учётом синтаксиса языка и назначения строк. Отдельная
система проверки комментариев не требуется.
