# Реализовать законченное изменение

Примени fstack:verify-result к критериям приёмки, fstack:no-comments к коду.
Для существенной неопределённости выбери приём через fstack:engineering-principles;
для зависимых этапов используй fstack:plan-work. Соблюдай порученную область
и инструкции проекта.

## Восстановить контракт

Прочитай затронутую реализацию, потребителей, тесты и конфигурацию. Установи
наблюдаемый результат, допустимые входы, ошибки и ограничения совместимости.
Неопределённость, влияющую на решение, разреши по исходникам или документации.

Выбери наименьшее законченное решение. Используй подходящий существующий
механизм; убирай устаревший путь в пределах поручения. Законченность включает
потребителей, миграцию, настройки и проверки. Малый diff с оставшимся сломанным
вызовом не является более простым решением.

## Изменить код и потребителей

Держи решения рядом с владельцем данных. Предпочитай явные входы, локальное
изменяемое состояние и прямой поток выполнения. Выделяй абстракцию для реальной
общей ответственности или повторяющегося решения, которое должно меняться вместе.

Не добавляй предполагаемые точки расширения, проходные слои и цепочки запасных
вариантов без поддерживаемого сценария. Сохраняй полезные границы. Используй
инструменты и диапазон версий проекта; новая зависимость требует конкретной
пользы. Проверяй первичную документацию для реальной неопределённости API или
версии, а не как обязательный ритуал.

Обнови необходимые вызовы и документацию изменившегося контракта. Согласуй
общие интерфейсы с их владельцем, сохрани чужие изменения и исключи постороннюю
уборку. Небольшой исполняемый пример полезен, если проясняет неоднозначный
критерий приёмки; его проверки должны защищать требование, а не повторять код.

## Завершить проверкой

Выполни содержательные проверки приёмки по verify-result, прочитай итоговый
diff и проверь оставшихся потребителей. При необоснованной сложности нового кода
примени fstack:simplify-change. Передай результат, изменения области,
существенные решения, доказательства и ограничения.
