# Скриншоты и видео в GitHub

Вложение полезно, если показывает результат UI-изменения, пару до/после
или воспроизведение и экономит ревьюеру запуск проекта. Для изменения,
полностью видимого в diff, оно обычно не нужно.

Проверь `gh <команда> --help`: в gh 2.99+ поддерживается повторяемый `--attach`
у команд PR и issue. Используй GitHub-инструменты, когда они выполняют нужную
операцию; CLI подходит для необходимой загрузки локального файла. Сам сбор
артефакта не разрешает публикацию или комментарий.

## Подготовка и загрузка

Сохрани и просмотри файл, исключи секреты и лишние персональные данные.
Проверь целевой репозиторий и PR. Тело Markdown передавай файлом.

```bash
playwright-cli screenshot --filename=settings-after.png
gh pr create --title "fix: сохранить имя после записи" --body-file body.md --attach "./settings-after.png#Форма после сохранения"
gh pr comment 123 --body-file comment.md --attach ./settings-flow.webm
```

Для встроенного изображения в теле используй `![Описание](./settings-after.png)`:
gh заменяет путь на URL загрузки. Невключённые в тело вложения добавляются
в конец по порядку флагов. Суффикс `#Описание` задаёт alt для изображения;
для видео alt не поддерживается.

Принимаются PNG, JPEG, GIF, WebP, SVG, MP4, MOV и WebM. Для изображений предел
10 МБ; для видео — 10 МБ на бесплатных тарифах и 100 МБ на платных.
Нужны права push; загрузка поддерживается на GitHub.com и GitHub Enterprise Cloud.
При ошибке сверяй актуальные ограничения и фактический ответ сервиса.

## Из CI

Сначала получи нужные артефакты конкретного прогона. Используй сохранённые
Playwright Test файлы из test-results, например при настройках
`screenshot: 'only-on-failure'` и `video: 'retain-on-failure'`.
Не публикуй весь каталог автоматически. Выбери минимальные относящиеся
к выводу файлы и передай каждый отдельным `--attach` без сборки shell-строки.

Для автоматической публикации нужны отдельно разрешённый workflow и
минимальные права на PR. Не раскрывай секреты в логах и не выполняй недоверенный
код PR с токеном публикации.

Запись демонстрации описана в [video-recording.md](video-recording.md).
