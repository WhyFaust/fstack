# Сессии браузера

Используй содержательное имя собственной сессии и передавай его каждому
вызову. Это разделяет cookies, localStorage, sessionStorage, IndexedDB, кэш,
историю и вкладки браузера, но не общее состояние сервиса или тестового стенда.

```bash
playwright-cli -s="$session" open "$url"
playwright-cli -s="$session" snapshot
playwright-cli list
```

Имя по умолчанию можно задать через `PLAYWRIGHT_CLI_SESSION`.
Не меняй его для чужой работы. Профиль обычно находится в памяти;
`open --persistent` сохраняет его на диске, `--profile=<каталог>` выбирает путь.
Не используй личный профиль пользователя для изолированного теста.

Headless-сессия по умолчанию закрывается после часа без команд; headed остаётся
открытой. `open --idle-timeout=<мс>` меняет предел, `0` его отключает.
Если процесс завершён, проверь состояние и открой свою сессию заново.

## Подключение к существующему браузеру

```bash
playwright-cli attach --cdp=chrome
playwright-cli attach --cdp=msedge
playwright-cli attach --cdp=http://localhost:9222
playwright-cli attach --extension
```

Для channel attach браузер должен разрешать remote debugging. Поддерживаются
семейства chrome и msedge с beta/dev/canary. Без явного `--session` имя
совпадает с каналом. Имя и доступную схему уточняй по установленному `--help`.
Не меняй настройки безопасности пользовательского браузера без поручения.

## Завершение и очистка

```bash
playwright-cli -s=msedge detach
playwright-cli -s="$session" close
```

`detach` предназначен для созданной через `attach` сессии и сохраняет внешний
браузер. `close` завершает собственный браузер, созданный через `open`.
Не используй массовое закрытие или уничтожение процессов как обычную очистку.

`playwright-cli -s=old-owned-session delete-data` удаляет профиль указанной
сессии. Перед этим установи, что данные принадлежат текущей работе, больше
не нужны и не используются. Не удаляй чужую авторизацию.

При параллельной работе разделяй не только имена сессий, но и профили,
каталоги артефактов и данные внешнего сервиса. Одна подключённая пользовательская
сессия не подходит нескольким независимым писателям.
