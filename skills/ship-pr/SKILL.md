# Выполнить разрешённое слияние

Из действующего поручения установи разрешение на merge или auto-merge,
целевой репозиторий, PR/MR, ветку назначения и способ. Уже выданное разрешение
действует; работа с кодом или создание PR сами по себе его не предоставляют.

Через fstack:watch-pr прочитай текущие head/base, approvals, обсуждения,
обязательные проверки и возможность слияния. Ревью должно относиться к текущему
изменению; поздние правки требуют проверки затронутого. Если пользователь
объявил собственное ревью, дождись его результата.

Зависимые PR/MR проводи от нижнего готового изменения. После каждого шага
перечитай состояние следующего. Целевую ветку, rebase и чужую историю нельзя
менять без соответствующего поручения.

Используй поддерживаемую операцию forge с ожидаемым head, если API это позволяет.
При несовпадении ревизии вернись к оценке готовности. Применимые защиты
сохраняются; административный обход не является способом завершить задачу.

Auto-merge не подходит для разрешения только на конкретную ревизию, если
сервис может затем слить неизвестные новые push. После действия перечитай
фактический исход, коммит и ветку. Queued и auto-merge enabled означают ожидание.

При потере ответа сначала установи результат записи. Наблюдай очередь только
в порученном режиме и сообщи фактический исход вместе с оставшейся работой.
