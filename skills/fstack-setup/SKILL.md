# Настроить профиль fstack

Это onboardingSkill плагина: нативный Setup и явный вызов навыка ведут сюда.
Просьба установить или обновить полный профиль разрешает обычную синхронизацию;
покажи краткий план и выполни её в этом же ходе. Не отправляй пользователя копировать
файлы или повторять команды. Запрос только проверки оставляет настройку без изменений.

Прочитай [руководство Codex](../../docs/codex.md). Определи фактический `CODEX_HOME`,
версию клиента, Python 3.11+ и включённый установленный плагин. Источник бери из
пути текущего навыка в каталоге клиента либо installedPath результата установки;
не угадывай версию кэша и не используй Git-клон вместо установленного пакета.
До записи проверь глобальный AGENTS.override.md и настройки, отключающие агентов
или переопределяющие роли. При конфликте подготовь конкретное исправление,
сохрани авторские инструкции и запроси решение только для неразрешённой замены.

## Сначала показать различие

`scripts/sync_profile.py` в корне пакета по умолчанию ничего не записывает.
Запусти его из полученного `installedPath` без `--apply`, при необходимости с `--home`.
Прочитай план и конфликты. Он относится только к пяти ролям, управляемому блоку
глобального `AGENTS.md` и собственному состоянию fstack.

При переходе со старого набора coder заменяет python_coder, добавляется verifier.
Прочитай removed и unmanaged_retired в плане. Helper удаляет только неизменённую
роль, которой владеет по сохранённому хешу; старые пользовательские копии
не удаляются. Модифицированная управляемая роль требует разрешения конфликта.

Для разрешённой настройки примени helper с `--apply`; он заново проверяет план
перед записью. `--adopt` допустим
только вместе с `--apply` при осознанном первом принятии отличающихся существующих
ролей или блока. Сначала покажи затрагиваемые файлы и используй уже выданное
разрешение, если оно явно охватывает замену; иначе получи решение пользователя.
Для вручную изменённого управляемого файла `--adopt` не является принудительной заменой.

Полный профиль включает согласование настроек по
[краткой справке](references/configuration.md). Сделай нужные правки сам в рамках
запроса; существующие предпочтения сохраняй. Helper управляет ролями и блоком,
а не config.toml. Показ примера конфигурации не означает завершённую настройку.

## Проверить итог

Прочитай фактический результат и повтори dry-run: при неизменном пакете он должен
показать отсутствие изменений. Проверь роль по её TOML и состояние fstack, затем
проверь, не скрывает ли AGENTS.override.md установленный блок координатора.
Неразрешённый override или выключенные агенты означают частичную настройку,
а не готовый профиль. Подтверди TOML, эффективные настройки и обнаружение доступными
средствами клиента. Для применения к новым агентам нужна новая сессия Codex.
Загрузка файлов не доказывает поведение агента; пробные модельные задачи не запускай.

Сопоставь доступные провайдеры с текущим каталогом. Отсутствующий Allure Analysis,
KISHKI, VaultGoblin, RTK или OpenAI Docs обозначь как ограничение конкретной задачи.
Не клонируй их навыки, не подключай аккаунты и не меняй чужие пакеты для завершения
настройки fstack. Не добавляй автоматический изменяющий профиль hook.

Для проверки именно установки в отдельном временном профиле доступен
`scripts/check_installation.py` из пакета; он требует уже установленный Codex
и PyYAML, не запускает модельные задачи и не меняет рабочий профиль.

Верни версию, целевой профиль, установленный набор ролей, результат повторного
dry-run, фактически выбранные модели и путь резервной копии. Отдельно назови
непроверенную доступность или оставшийся конфликт; полные файлы в ответ не включай.
