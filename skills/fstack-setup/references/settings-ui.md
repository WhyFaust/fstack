# Настроить профиль в беседе

Манифест задаёт стартовые запросы для карточки плагина: полный профиль, настройки
и проверку. Если клиент их не показывает, используй явный вызов навыка.
Они запускают беседу с навыком; отдельной формы настроек fstack в
проверенном публичном формате плагинов нет. Не утверждай, что открыл такую форму.

## Показать текущие значения

Определи установленный пакет, целевой CODEX_HOME и действующие слои по
[справке конфигурации](configuration.md). Покажи компактную таблицу:

| Параметр | Что показать и изменить по запросу |
| --- | --- |
| Модель профиля | Действующий единый выбор для координатора и исполнителей, исходно gpt-6.1-sol; отдельно показать различие между уровнями |
| Reasoning координатора | Текущее значение и поддерживаемые варианты |
| Reasoning исполнителей | Текущее значение по умолчанию; отдельное поручение может задать подходящий уровень |
| Параллельность | Действующий лимит потоков с учётом ограничений клиента |
| Делегирование | Включено ли оно и какой слой задаёт это значение |

Это настройки профиля Codex, которыми пользуется fstack; они могут влиять на
другие чаты этого профиля. Переключатель модели текущего чата и сохранённые
значения по умолчанию проверяй отдельно. Не показывай секреты или полный config.

## Получить нужный выбор

Если пользователь уже задал значения, используй их без повторного опроса.
Запрос «покажи» или «проверь» заканчивается отчётом без записи. При запросе
изменения уточняй только параметры, для которых желаемое значение неизвестно.
Простой полный Setup не требует анкеты: сохраняй действующие предпочтения
и используй согласованные defaults для отсутствующих значений.

Если в текущем главном потоке доступен request_user_input, предложи короткие
вопросы с поддерживаемыми вариантами reasoning и лимита. Если инструмент
недоступен, задай такой же короткий вопрос в беседе. Не включай экспериментальные
флаги, не меняй режим клиента и не создавай подагента ради карточек выбора.
Не спрашивай модель заново: исходный выбор fstack — gpt-6.1-sol, а последний
явный выбор пользователя для профиля имеет приоритет. Новый запрос смены модели
обрабатывай по фактическому каталогу для указанной области.

Варианты reasoning бери из каталога настроенной модели. Для параллельности
предложи текущее значение и подходящие альтернативы в пределах клиента;
значение должно быть положительным целым. Не выдавай повышение лимита за
ускорение общего стенда: независимость ресурсов всё равно обязательна.
Отмена или сохранение текущих значений не создаёт запись и резервную копию.

## Применить выбранное

Покажи различие «было → станет» и выполни порученную правку по
[справке конфигурации](configuration.md), без повторного общего согласования.
Меняй только выбранные поля. Запрос настроек не разрешает копировать роли,
обновлять AGENTS.md, устанавливать плагины или включать отдельные интеграции.
Если профиль ещё не установлен, сообщи об этом и предложи полный Setup;
просмотр настроек не является поручением установки.

Единый выбор модели для профиля записывается в model и
agents.default_subagent_model. При выборе только reasoning или лимита модель
не меняй. Новое явное значение заменяет прежнее предпочтение только в указанной
области. Прочие поля и ограничения сохраняются.

После записи проверь TOML, эффективные значения и источник переопределений.
Верни изменённые поля, сохранённые значения и ограничения проверки. Настройки
старта относятся к новой сессии; фактическая модель текущего чата не меняется
от текста инструкции. Не запускай пробные задачи моделей.
