# Проверка после переноса

Проверь версию клиента, источник и версию плагина, список навыков нового чата и
доступные инструменты. Подготовка профиля не разрешает тестовые задачи с внешними
моделями или сервисами: для них нужен согласованный эксперимент.

Если профиль использует роли или MCP, сверь их имена и исполняемые файлы на устройстве.
Локальный baseline или проверяющий скрипт используй только когда он действительно
существует и его область проверки известна. fstack не поставляет персональный
baseline, настройки ролей, MCP или скрипт проверки чужого профиля.

В Settings → Hooks проверь источники и доверие, если переносимый профиль содержит
хуки. Не переноси доверие изменением хешей TOML. Загрузка конфигурации не доказывает
фактического выполнения события. Учетные данные настраивай штатным способом сервиса.
При отсутствии зависимости останови зависимую работу и обозначь расхождение;
независимая работа может продолжаться.
