# Определить срок жизни ресурсов

Установи владельца и срок жизни каждого ресурса. Переиспользуй существующий
ресурс с известным состоянием, сохраняя границу владения.

Регистрируй очистку сразу после получения ресурса, чтобы пережить неполный
setup, сбой сценария и повтор. При сбое очисти остальные независимые ресурсы.
Сохрани первичный отказ и отдельно укажи ошибку очистки.

Разделяй ключи, пути, данные и порты работников. На общей VM или БД проверяй
владение независимо от worktree. Опиши общую фикстуру и правила её изменения.

Освобождай свои объекты по проверенному ID. При потере ответа о создании
сначала выясни исход по [$fstack:state](../state/SKILL.md).

Проверь сбой посреди setup и при teardown. Для Python и pytest применяй
[$fstack:python](../python/SKILL.md). Сохрани доказательства вне очищаемой среды.
Перечисли освобождённое, оставшееся и владельца следующих действий.
