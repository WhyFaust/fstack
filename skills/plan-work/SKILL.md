# Спланировать последовательность работы

## Вход и границы

Опирайся на цель, критерии, полномочия и проверенные факты текущего поручения.
План нужен, когда результаты требуют существенного порядка или согласования
входов, а не ради перечисления действий. Координатор использует краткие итоги
и источники владельцев; подробное исследование реализации не повторяет.
План исполнителя ограничен его областью и не пересоздаёт общий план.

## Порядок работы

### Построить порядок этапов

Выдели законченные результаты. Для каждого назови вход, зависимость, владельца
и наблюдение готовности. Не дели обычные действия на отдельные фазы и не вводи
обязательный файл или формат: достаточно краткого порядка.

Отдели подтверждённые входы от предположений. Для блокирующего неизвестного
назови наблюдение или выбор, который нужен до зависимого этапа. Исследуй только
этот вопрос в разрешённых границах. При запросе только плана допустимо оставить
явный исследовательский шаг вместо неподтверждённого решения.

Изменение контракта и потребителей упорядочи с допустимым промежуточным
состоянием. Для переходного периода примени fstack:migrate-contract; для
существенного выбора модели или интерфейса — fstack:design-change.
Независимые результаты можно выполнять параллельно по fstack:delegate-work,
если ресурсы независимы; неподтверждённый вход блокирует только своих потребителей.

## Проверка и результат

### Выполнить и обновить план

Сопоставляй итог этапа с его входом и критерием по fstack:verify-result.
Подробный diff и доказательства изучает назначенный автор или проверяющий;
координатор принимает краткий итог. При изменении предпосылок пересмотри только
затронутые зависимости и проверки, сохрани выполненное и причины новых решений.

Не создавай отдельные PR, падающие коммиты или тестовый набор ради структуры
плана. Разрешения и состояние дерева определяют уместность этих действий.
Для паузы сохраняй состояние по fstack:checkpoint-task без копирования журнала.

Передай короткий порядок, условия готовности и оставшиеся вопросы. Если
реализация уже поручена, продолжай без повторного согласования того же плана;
при запросе только плана закончи на нём.
