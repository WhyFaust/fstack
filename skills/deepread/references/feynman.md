# Проверка понимания по Фейнману

1. Выбери понятие или механизм, который пользователь хочет освоить.
   Выдели по источнику тезис, ключевые определения, связи и доказательства.
2. Попроси пользователя отложить источник и объяснить механизм своими
   словами по памяти. Если пользователь ещё не отвечал, дай ему вопросы
   для самостоятельной проверки и дождись ответа для диагностики понимания.
3. Сопоставь объяснение с реестром. Найди первый пропущенный переход,
   неясное определение, потерянное свидетельство или забытое ограничение.
4. Вернись к нужному месту источника и предложи исправить этот фрагмент.
   При использовании аналогии укажи, где она перестаёт работать.
5. Дай новый пример и попроси предсказать результат. Затем предложи случай,
   где условия метода не выполнены, и попроси объяснить границу применимости.
6. Подготовь вопросы для следующего повторения по памяти: о механизме,
   его доказательстве и существенном ограничении.
