# Запуск агентов Codex

Проверь доступные типы и параметры в схеме инструмента текущей сессии.
Если выбор типа необязателен, при обычном запуске передай область задачи,
обязанности и нужный навык в тексте поручения.
[Критерии выбора исполнителя](../SKILL.md#назначить-владельца).

При обычном запуске модель и reasoning определяет конфигурация Codex и
выбранная роль, включая её проектные или личные настройки. Передавай `model` и `reasoning_effort` только если
их выбор явно нужен по поручению и клиент разрешает поля. Настройки профиля
для одного запуска менять не требуется. Если заданные параметры недоступны,
сообщи точное ограничение.

Для независимой проверки выбирай свежий контекст. В клиентах с `fork_turns`
используй `fork_turns="none"`, если он доступен. Если клиент предоставляет
другой механизм, проверь его значение по фактической схеме. Свежему агенту
передай самодостаточное задание с ревизией, критериями и первичными данными.

Границы доступа и инструментов задаёт среда. Ограничение в тексте поручения
задаёт ответственность исполнителя. Сверь полномочия до запуска.
Перед сменой исполнителя проверь состояние его ресурсов и завершение работы.
После повторного отказа уточни вход или причину сбоя по наблюдаемым данным.

[Документация Codex о подагентах](https://developers.openai.com/codex/subagents).
