# Модель и reasoning для поручения

Исходная модель координатора и всех исполнителей — gpt-6.1-sol. Последний явный
выбор пользователя для всего профиля заменяет этот default и применяется к обоим
уровням агентов. Явное значение для отдельного поручения действует только в нём.
Роль задаёт ответственность, reasoning выбирается по задаче. Сохраняй настроенную
модель при изменении сложности работы; сам не переключай её на другую.

Это начальная политика fstack, без измерений на проектах пользователя.
Проверяй доступность настроенной модели и уровней по текущему каталогу клиента.
Пользовательский reasoning из действующего профиля служит отправной точкой;
таблица не отменяет его. Для отдельного поручения меняй effort по объёму и риску,
сохраняя явно заданный пользователем уровень для этой задачи.

## Начальный выбор

| Работа | Reasoning |
| --- | --- |
| Главный координатор, краткие решения по отчётам | low |
| Узкое чтение, извлечение фактов, известная команда или статус CI | low |
| Группировка Allure и исследование с ясными границами | medium |
| Исследование нескольких модулей, обычная реализация, интеграционный сценарий | medium |
| Локальная правка с ясным контрактом или работа через экран | medium |
| Независимое ревью обычного diff | medium |
| Сложный дефект, конкуренция, противоречивые доказательства или существенные крайние случаи | high |

При отсутствии другой настройки профиля исходный уровень исполнителя — medium.
При неясном объёме начни с короткого
исследования. Узкий запуск команды и объяснение сложного отказа — разные поручения.
Повышай до high под конкретный риск или оставшуюся неопределённость, а не по
названию роли. Более высокие поддерживаемые уровни используй только под
обоснованный трудный случай; они не становятся настройкой по умолчанию.

## Применить настройки фактически

Используй параметры инструмента запуска, если они доступны. Укажи настроенную
модель и выбранный effort: наследованное усилие может не подходить задаче. Для отдельного
контекста используй поддерживаемый режим без истории. При полном наследовании
инструмент может запретить переопределения; не передавай несовместимые параметры.

В поставляемых файлах ролей нет model и model_reasoning_effort: эти поля Codex
применяет поверх выбора при запуске. Явный выбор при запуске имеет приоритет над общими
[agents] defaults; без него действует настроенный default либо наследование.

Если инструмент не позволяет задать модель или effort, проверь фактические
настройки потока. Продолжай при их соответствии поручению; иначе верни координатору
ограничение совместимости. Текст поручения сам по себе модель не переключает.
Главный агент также не меняет себя инструкцией; конфигурация задаёт старт,
а сложный отдельный вопрос можно передать исполнителю с нужным уровнем.

При недоступности настроенной модели или нужного уровня сообщи координатору
о блокировке. Если каталог недоступен, используй только ранее подтверждённую
настроенную модель и поддерживаемый effort; укажи, что свежая проверка недоступна.
Не подбирай другой идентификатор и не меняй глобальный профиль ради одного поручения.

## Повысить уровень по причине

Если задача не укладывается в исходные предпосылки, запроси у исполнителя факты,
неудачную проверку и оставшийся вопрос. Сначала исправь недостающий вход или
границу задачи. При подтверждённой сложности повысь effort до high и передай
краткий контекст новой попытке на той же модели. Не дублируй активного писателя;
перед заменой останови прежнего и проверь фактические изменения его ресурсов.

Повтор без новых данных, одинаковое нарушение проверки или попытка ослабить
контракт требуют пересмотра решения. Отсутствие доступа, инструмента или
зависимости обозначается как блокировка. Повышение effort не создаёт эти права.
Оценивай готовый результат и цену исправлений; отдельные модельные evals не запускай
без запроса. Точные источники и ограничения приведены в документации оркестрации.
