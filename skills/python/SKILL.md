# Python

Применяй правила репозитория и основной метод. Используй
[$fstack:verify](../verify/SKILL.md) для доказательств и
[$fstack:no-comments](../no-comments/SKILL.md) при правке кода.

## Окружение и зависимости

Установи версии Python и ОС, окружение, менеджер, lock-файл и команды.
Используй formatter, linter и type checker проекта. Начни со стандартной
библиотеки и текущих зависимостей. Меняй зависимости и lock по необходимости,
читай нужные записи. Сверяй контракт по документации выбранной версии.
Проверь доступность синтаксиса, импортов и API на минимальной версии, удаления
и изменения на более новых поддерживаемых версиях.

## Код и контракты

Отдели расчёт по проверенным данным от I/O. Для смены I/O передавай функцию
или клиент явно. Наследуй при сохранении контракта или требовании фреймворка.
Следуй соглашениям модулей и импортов, исключи эффекты при импорте.

Опиши контракт типами и валидируй внешние значения при выполнении. Избегай
широкого Any, маскирующего default и подавления ошибки. Перехватывай конкретное
исключение у операции для обработки или перевода через `raise ... from exc`
с контекстом. Остальное передавай вызывающему.

Укажи кодировку, используй pathlib. Назначь владельца и очистку файлов,
соединений, процессов и задач. Сохрани первичную ошибку при сбое cleanup.
Для subprocess учти код выхода, stderr, timeout и оболочку.

## Асинхронный код и тесты

В event loop используй `await`. Вынеси блокирующий I/O с учётом потоковых
ограничений. Владелец фоновой задачи ждёт итог и обрабатывает ошибку. При
отмене освободи ресурсы и передай `CancelledError`. После таймаута возможной
внешней записи установи исход перед повтором.

Проверяй наблюдаемый эффект через штатный вход. Разделяй независимые контракты,
параметризуй варианты с отдельными данными, неделимый переход проверяй одним
сценарием. Подменяй зависимость в месте использования. В pytest регистрируй
очистку сразу после получения ресурса: при сбое подготовки до `yield` код
после него не выполнится. Изолируй данные общего сервиса по запуску и работнику:
scope `session` в pytest-xdist действует внутри процесса.
[Документация pytest](https://docs.pytest.org/en/stable/how-to/fixtures.html)
