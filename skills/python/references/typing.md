# Типизация и внешние данные

Сначала установи версию Python, принятый type checker и контракт изменяемого
интерфейса. Не добавляй отдельный инструмент типизации ради одной правки.

Опиши допустимые значения и состояния. Различай отсутствующее значение,
пустую коллекцию и ошибку. Если после проверки None невозможен, сохрани
это знание в потоке программы вместо широкого Optional во всех слоях.

TypedDict подходит для формы словаря, dataclass — для предметного значения,
Protocol — для необходимого поведения. Выбор должен соответствовать существующим
границам проекта; одни только аннотации не проверяют данные во время исполнения.

Для общего `Protocol` выпиши операции, которые действительно вызывает
потребитель, и типизируй его вход этим интерфейсом. Сверь у каждого клиента
способ передачи аргументов, возвращаемый тип, значение отсутствия и ошибки.
Подходящие реализации совместимы структурно. Если клиенты возвращают разные
форматы или по-разному сообщают об отсутствии данных, преобразуй их на границе
в общий предметный контракт. Запусти настроенный type checker на потребителе
с каждой поддерживаемой реализацией. `@runtime_checkable` проверяет наличие
членов и не подтверждает совместимость сигнатур или семантику.

JSON, конфигурацию, API-ответ и пользовательский ввод проверяй на границе.
Используй авторитетную схему или уже установленный валидатор. Не создавай
две расходящиеся модели одного контракта. NewType и cast не заменяют валидацию.

Any допустим на известной динамической границе с локальной причиной.
Не распространяй его по проекту, чтобы убрать диагностику. Подавление должно
иметь подтверждённое основание; содержательный дефект требует исправления.

Учитывай изменяемость контейнеров и разделяемые значения по умолчанию.
Не выдавай поверхностную неизменяемость объекта за защиту вложенного состояния.
Проверь изменённый интерфейс на его реальных потребителях и настройках проекта.

API сверяй со [спецификацией Protocol](https://typing.python.org/en/latest/spec/protocol.html),
[документацией typing](https://docs.python.org/3/library/typing.html)
и [dataclasses](https://docs.python.org/3/library/dataclasses.html) для версии проекта.
