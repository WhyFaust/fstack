# Подготовить план выбранного улучшения

## Вход и границы

Возьми выбранную проблему, путь к плану или ID. Определи цель, полномочия,
ограничения и потребителей. Планируй без правок исходников, зависимостей и общих
ресурсов. Поиск и приоритеты веди через [$fstack:audit](../audit/SKILL.md).

## Порядок работы

Найди индекс и план той же причины. Сверь исходный снимок, HEAD, staged,
unstaged, untracked, потребителей и доказательства. Для решённой проблемы
обнови статус с подтверждением. Для нового плана укажи ветку, полный SHA, базу,
индекс и рабочее дерево с untracked. Значимые локальные входы привяжи к путям
и хешам или согласованному снимку. Вне Git опиши доступный снимок и пределы.

Укажи ID, исходный сценарий, цель, файлы и решения. Для зависимых шагов укажи
вход, действие и наблюдаемый итог. По проекту сверь предпосылки, область,
потребителей, совместимость, приёмку, команды и побочные эффекты. Для дефекта
планируй исправление, для гипотезы — различающее наблюдение и решение по исходу.
Для интерфейса применяй [$fstack:design](../design/SKILL.md), для зависимостей —
[$fstack:plan](../plan/SKILL.md). Ищи ответы в проекте. Уточняй выбор, только если он меняет результат.

Отдай в запрошенном формате. При записи сохрани индекс, нумерацию, расположение,
чужие документы и историю основания. Для нового индекса укажи ID, приоритет,
зависимости, статус и ссылку по [$fstack:audit](../audit/SKILL.md). Секрет
обозначай только типом и местом.

## Проверка и результат

Проверь, что по плану и снимку можно определить границы, выполнить шаги и
отличить успех от отказа. Для существенного плана получи разрешённое ревью по
[$fstack:review](../review/SKILL.md) или укажи пробел. Передай план, основание,
открытые вопросы и непроверенные предпосылки. При порученной реализации
передай исполнителю снимок с локальными изменениями, проверь зависимости
в его копии и владельца общих ресурсов.
