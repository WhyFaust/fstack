# Подготовить план выбранного улучшения

[Каталог · Планирование](../../docs/skills.md#планирование)

Цитата не включает навык. Вне faust-mode применяй только явно вызванные навыки.

Для выбранной проблемы найди существующие план и индекс по ID или причине.
Планирование оставляет исходники, зависимости и общие ресурсы без изменений.
Поиск и приоритеты ведёт [audit](../audit/SKILL.md).

Сверь сценарий и потребителей на текущем снимке. Зафиксируй ветку, полные
base/head SHA, staged, unstaged и untracked. Значимые локальные входы привяжи
к путям и хешам или согласованному снимку. Вне Git укажи доступную основу
и ограничения. Для уже решённой проблемы обнови статус с доказательством.

В плане укажи цель, границы, файлы и решения. Для шага дай вход, действие,
наблюдаемый успех и отказ. Для гипотезы укажи проверку и решение по исходу.
Сверь предпосылки, совместимость, команды и побочные эффекты с проектом.
[Упорядочь зависимости](../plan/SKILL.md). Секреты обозначай только типом
и местом.

Сохрани формат, нумерацию, чужие планы и историю основания. В новом индексе
нужны ID, приоритет, зависимости, статус и ссылка. Для существенного плана
получи разрешённое [ревью](../review/SKILL.md) или назови пробел. При порученной
реализации передай исполнителю точный снимок с локальными входами, сверь
зависимости в его копии и владельцев общих ресурсов.
