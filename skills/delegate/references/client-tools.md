# Параметры запуска и проверка результата

Определи возможности текущего сеанса по доступным инструментам и их схемам.
Используй аргументы выбранного инструмента. Явно заданные провайдер,
модель, глубина и изоляция остаются требованиями поручения.

## Запуск исполнителя

| Возможность клиента | Что передать при запуске | Подтверждение |
| --- | --- | --- |
| Нативный запуск с отдельным контекстом | Передай самодостаточное поручение, выбери свежий контекст и укажи глубину через параметры запуска | Клиент зарегистрировал запуск и подтвердил заданную глубину |
| Запуск у другого провайдера или в отдельном worktree | Сверь доступные модели и параметры в каталоге возможностей, если он есть. Выбери нужного провайдера и изоляцию в схеме запуска | Сверь провайдера и ревизию рабочего снимка. Продолжи по сигналу завершения клиента |

Если пользователь просит полную историю, проверь наследуемые параметры по
схеме. Если требуемое сочетание недоступно, сообщи об этом до запуска.

## Мониторинг PR

Если клиент предоставляет наблюдение за PR, передай его полный URL и выбери
условие завершения, соответствующее поручению. Для ожидания CI это завершение
проверок. После уведомления перечитай PR и сверь статус нужного head.
Пока клиент сам возобновляет работу по событию, отдельные опросы не нужны.

## Браузер

Для указанной вкладки проверь список вкладок подключённого браузера, выбери
нужную и возьми локатор из свежего снимка. Для отдельного прогона через
Playwright CLI используй отдельную сессию и сверь команды по справке
закреплённой версии. Подтверди ожидаемое состояние в той же вкладке после действия.
