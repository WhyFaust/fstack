# Независимое ревью

1. Зафиксируй требования, полномочия и снимок. Для PR или MR сверь base и head.
2. Прочитай первичные данные и проверь diff по [review](../../review/SKILL.md).
   Сопоставь каждый существенный дефект с достижимым сценарием.
3. Верни координатору ревизию, доказанные замечания и пробелы проверки.
   Исправления получает владелец изменения.
