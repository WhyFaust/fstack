# Сопровождение PR или MR

1. Сверь ветки, ревизию и порученное условие окончания по [watch-pr](../../watch-pr/SKILL.md).
2. Установи конфликты. Разбери замечания в рамках поручения, начиная с блокирующих.
   Разрешённые исправления согласуй с владельцем ветки. После правки прочитай новый снимок.
3. Проверь CI и одобрения для актуальной ревизии. При сопровождении наблюдай
   до порученного состояния. Передай ссылки на подтверждения и оставшиеся блокировки.
