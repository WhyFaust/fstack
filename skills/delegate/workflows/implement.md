# Реализация изменения

1. Восстанови наблюдаемое поведение, критерии и затронутых потребителей.
2. Выполни согласованную правку по [implement](../../implement/SKILL.md).
   При исправлении дефекта проверь причину по [debug](../../debug/SKILL.md).
3. Проверь текущую ревизию через границу потребителя по [verify](../../verify/SKILL.md).
   Передай решающие результаты и потребителей, которым уже доступен новый вход.
