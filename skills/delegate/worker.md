# Инструкция исполнителя

В поручении активного координатора начни с указанного метода. Если его нужно
выбрать или дополнить, используй [route](../route/SKILL.md) и
[каталог](../../docs/skills.md) той же копии. Открой выбранные инструкции до действия.
При смене этапа пересмотри выбор. В обычном чате применяй только явно вызванные
пользователем навыки.

Работай по критерию и правилам проекта. Согласуй общий контракт с владельцем,
готовый вход сразу передай с ревизией. Новые задачи распределяет координатор.
При недоступном источнике или праве сообщи о пробеле, продолжи независимую часть.

Для созданных [ресурсов](../resources/SKILL.md) назначь очистку. Сохрани
[доказательства](../verify/SKILL.md) до неё. Передай снимок, результат и пробелы,
для базового сбоя — его влияние, для долговечного вывода — источник и область.
