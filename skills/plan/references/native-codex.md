# Plan и Goal в Codex

Проверь режим и доступные инструменты текущего чата. Команда в поле ввода
`/plan` переключает режим клиента. Если запрос уже запущен в Plan Mode,
собери факты чтением, уточни только существенные неизвестные и представь
план штатным способом. Продолжи по этому плану после перехода к исполнению.
[Команды приложения](https://learn.chatgpt.com/docs/app/slash-commands)

В режиме исполнения для разрешённой многоэтапной задачи используй доступный
инструмент ведения плана. Если инструмента нет, зафиксируй краткий план в чате
и выполни поручение. Если пользователь просит именно Plan Mode, а в ходе
отсутствует штатное переключение, укажи команду `/plan` для поля ввода.

При прямой просьбе установить цель проверь её состояние через `get_goal` и
поставь её через `create_goal`, если клиент предоставляет эти инструменты.
Передай исходный результат, границы и наблюдаемые критерии готовности.
Учитывай лимит, если пользователь его задал.
При работе по активной цели сверяй выполненные этапы и проверки, сохраняя
решения текущего чата. Заверши цель через `update_goal` по подтверждённым критериям.
Действия с паузой, заменой и удалением цели следуют
прямым указаниям пользователя и возможностям клиента. Если цель может
установить только пользователь, передай ему готовое содержание для `/goal`.
[Работа по цели](https://learn.chatgpt.com/docs/long-running-work)

Короткая работа и уже исполняемый план требуют обычного продолжения чата.
Фиксируй план и цель в доступных средствах клиента. Проектный файл для
состояния задачи создавай по поручению или принятому порядку проекта.
