# Спланировать последовательность работы

[Каталог · Планирование](../../docs/skills.md#планирование)

Цитата не включает навык. Вне faust-mode применяй только явно вызванные навыки.

До правок свяжи каждый этап с входом, владельцем и наблюдаемой готовностью.
Для блокирующего неизвестного укажи исследование и наблюдение, которое
разрешит выбор. Для смены контракта предусмотри [совместимый переход](../migrate/SKILL.md).
Для стека PR/MR укажи базу и проверку каждого изменения. Например, сначала
слей чтение обоих форматов данных, затем переведи запись на новый формат.
После смены базы проверь diff второй ветки, создание новой записи и чтение
старой. Независимое изменение можно вести от основной ветки.

По запросу плана закончи на плане. При порученной реализации начинай этап
по готовности входов и ресурсов. Прими результат по [verify](../verify/SKILL.md).
Автор или проверяющий читает весь diff своей области, координатор сверяет
доказательства. Смена входа требует пересмотра зависимых шагов и проверок.
При паузе сохрани [точку продолжения](../checkpoint/SKILL.md).

## Plan и Goal в Codex

В Plan Mode исследуй вопрос чтением и представь план в формате клиента.
К исполнению переходи после смены режима. Если пользователь просит Plan Mode,
а переключение из хода недоступно, укажи команду `/plan` для поля ввода.
При выполнении веди этапы инструментом плана или в чате. Файл для состояния
создавай по поручению или правилам проекта. [Команды приложения](https://learn.chatgpt.com/docs/app/slash-commands)

По прямой просьбе установить цель вызови `get_goal`, затем при необходимости
`create_goal` с результатом, границами, критериями и заданным пользователем лимитом.
Если установить цель может только пользователь, дай текст для `/goal`.
Завершай цель через `update_goal` после проверки критериев. Для паузы,
замены и удаления соблюдай указания пользователя и возможности клиента.
[Работа по цели](https://learn.chatgpt.com/docs/long-running-work)
