# Использовать общие знания

[VaultGoblin](https://github.com/WhyFaust/VaultGoblin) — отдельный плагин Faust.
Он экспортирует темы локальной памяти Codex в общий слой Obsidian; перенос
между устройствами выполняет настроенная синхронизация vault. fstack
не копирует его код, заметки, настройки, hooks или локальный индекс.

Найди в текущем каталоге навык codex-shared-knowledge плагина VaultGoblin
и прочитай его оригинальную инструкцию. Для настройки нужен его
vaultgoblin-setup, только если настройка поручена. Не угадывай исполняемый
путь, имя инструмента, состояние синхронизации или наличие авторизации.

Для существенной работы в знакомом проекте один раз получи ограниченную
релевантную историю по правилам провайдера. Не обходи весь vault и чужие чаты.
Используй источники и даты; исторические CI, MR, версии и состояние стенда
сверяй по текущим данным. Память не выдаёт разрешений и не заменяет требования.

Пустая выдача и предупреждение о неполной синхронизации — разные результаты.
Если плагин недоступен, обозначь это для зависимого вывода и продолжи
по текущим исходникам. Не устанавливай его и не меняй доступ ради обычной задачи.

Настроенная автоматизация VaultGoblin отвечает за экспорт; не добавляй
экспорт в конец каждого чата. Локальные пути и индекс различаются на Windows
и Linux. Для оперативной передачи задачи используй fstack:checkpoint-task
и fstack:resume-task; память не переносит незакоммиченный код и живые процессы.
