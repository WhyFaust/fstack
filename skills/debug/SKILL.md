# Найти причину и исправить сбой

[Каталог · Исследование](../../docs/skills.md#исследование)

Цитата не включает навык. Вне faust-mode применяй только явно вызванные навыки.

1. Зафиксируй ожидание, ревизию, запуск, попытку и среду. По цепочке ошибок
   найди первую нарушенную предпосылку. Воспроизведи именно этот сбой через
   штатный вход. Сохрани полный пример, сокращай по одному условию. Без запуска
   укажи границу доказанного.
2. Выбирай наблюдение по симптому. Для зависания сними стеки, для CPU — профиль,
   для памяти сравни удерживаемые объекты, для гонки — порядок событий. Фиксируй
   нагрузку, seed, интервал и влияние диагностики. Убери временные средства,
   в отчёте сохрани разрешённый артефакт без закрытых данных.
3. Найди владельца и переход, допустивший нарушение. Различи причины проверкой
   при прочих равных. Перед очередной правкой перепроверь общую предпосылку
   неудачных попыток, убери опровергнутые изменения. Для задержки установи объём
   полезной работы и возможность убрать лишнее до изменения лимитов, повторов
   или параллелизма. Сравни [варианты](../design/SKILL.md) по результату для
   потребителя, сохранности данных и диагностики.
4. Свяжи причину, механизм исправления и наблюдение восстановления. При порученной
   диагностике верни диагноз и доказательство, внешнему владельцу — воспроизведение.
   Временный обход требует явного запроса, описания остаточного дефекта и условия удаления.
5. При порученной правке исправь причину у владельца и обнови потребителей.
   По [implement](../implement/SKILL.md#предотвратить-повтор-ошибки) проверь отказ
   до и успех после. Повтори **полный исходный пример без обхода** и соседние
   контракты. Для нестабильности нужны повторы или управление порядком событий.
   Укажи команду, условия, обе ревизии и непроверенные гипотезы.
