# Навыки fstack

[Каталог всех навыков по задачам](../docs/skills.md)

## Как выбрать метод

| Задача | С чего начать |
| --- | --- |
| Почему здесь очередь? | [how](how/SKILL.md) проследит текущий путь запроса, [why](why/SKILL.md) найдёт историю решения, [debug](debug/SKILL.md) разберёт зависание. |
| Проверить установку | [test](test/SKILL.md) пройдёт сценарий. [verify](verify/SKILL.md) сверит уже собранные доказательства с критериями. |
| Подготовить проверку для команды | [test-setup](test-setup/SKILL.md) составит новую инструкцию, [test-update](test-update/SKILL.md) обновит устаревшие шаги. |
| Добавить повтор запроса в Python API | [implement](implement/SKILL.md) ведёт правку. Перед изменением проверь [структуру кода](no-comments/SKILL.md), [особенности Python](python/SKILL.md) и [повторную запись](state/SKILL.md). |
| Разобрать большой лог и подготовить отчёт | [rtk](rtk/SKILL.md) сокращает вывод команд, [debug](debug/SKILL.md) устанавливает причину. Для отчёта пригодится [write](write/SKILL.md), перед сдачей — [unslop](unslop/SKILL.md). |

В обычном чате можно вызвать `$fstack:route`, чтобы получить подбор для своей задачи.
