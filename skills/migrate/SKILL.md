# Провести переход на новый контракт

[Каталог · Реализация](../../docs/skills.md#реализация)

Цитата не включает навык. Вне faust-mode применяй только явно вызванные навыки.

Сопоставь старый и новый контракт. Найди потребителей в коде, настройках,
данных, документации и примерах. Совместно выпускаемые компоненты переведи
одним изменением. Для независимых релизов определи порядок, срок поддержки
и допустимые сочетания версий. Назначь владельца и условие удаления адаптера.

Переходи по завершённым участкам. Для данных определи порядок остановки,
повтора и восстановления по [state](../state/SKILL.md). Проверь чтение новой
записи старой версией при откате. Проверь оставшиеся ссылки и сочетания версий,
обнови публичную версию и инструкцию перехода.
