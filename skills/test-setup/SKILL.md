# Описать воспроизводимую проверку

[Каталог · Проверка](../../docs/skills.md#проверка)

Цитата не включает навык. Вне faust-mode применяй только явно вызванные навыки.

Создай инструкцию для повторяемой проверки через реальную границу. Возьми
пользовательский путь, проектные команды, доступ и тестовые данные. Попробуй
минимальный [сценарий](../test/SKILL.md). Новый harness нужен при подтверждённом пробеле.

В принятом проектом месте запиши рабочий каталог, версии, команды, входы,
признак готовности и наблюдаемый успех. Укажи владельца процесса, порта и
данных, изоляцию, очистку и место артефактов. Для нескольких путей свяжи
названия из задачи или UI с командами, доступом и результатом.

Пройди один путь по готовому тексту с указанных в нём исходных данных.
Подготовь среду, выполни команды, получи результат и проведи очистку.
Открой сохранённое доказательство по указанному пути. Если потребовалось
ручное действие, добавь его и повтори затронутую часть.
Обозначь подменённые границы, при блокировке укажи
непроверенные шаги и причину. Для правки существующей инструкции применим
[test-update](../test-update/SKILL.md).
