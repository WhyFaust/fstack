# Упростить готовое изменение

[Каталог · Реализация](../../docs/skills.md#реализация)

Цитата не включает навык. Вне faust-mode применяй только явно вызванные навыки.

Прочитай требования, проверки и весь порученный diff, включая коммиты.
Для нового слоя, параметра, копии состояния или запасного пути найди
фактический сценарий. Убери избыточное в затронутых файлах. Объединяй
код по общей причине изменения, сохраняй владение, доверие, ошибки
и совместимость.

Вырази назначение [именами](../no-comments/SKILL.md), убери временную
диагностику. Проверь, что default, подавление исключения или retry не скрыли
дефект. [Повтори проверку](../verify/SKILL.md) через потребителя. Покажи
устранённую сложность и сохранённое поведение. Оставь diff как есть, если
обоснованной правки нет. Для широкой перестройки нужен [refactor](../refactor/SKILL.md).
