# Установить исход вызова инструмента

Ответ инструмента сохрани в памяти до разбора. Сначала проверь ошибку и форму,
затем используй подходящий structuredContent или ожидаемый JSON текстового блока.
Ошибка разбора не заменяет причину отказа. В отчёт и артефакты передавай только
безопасный код или смысл ошибки, без секретов, заголовков и сырого тела ответа.

Различай вызов, ожидание одобрения/отправки, подтверждённый старт и целевой исход.
Timeout не доказывает ни запуск, ни отсутствие записи. При неизвестном исходе
сначала разрешённо прочитай целевое состояние. Отказ политики/доступа не обходи
другим инструментом. При недоступном MCP или повторных timeout допустимый
резерв выбирай после сверки состояния, области и авторизации; наличие MCP
в каталоге не подтверждает выполнение.
