# Использовать RTK

## Вход и границы

Проверь доступность, версию и местную инструкцию [RTK](https://github.com/rtk-ai/rtk).
fstack не устанавливает RTK, не меняет hooks и не включает API-прокси.
Учитывай пути текущей ОС. Без RTK работай обычными командами.

## Порядок работы

Проверь действующий hook. Применяй только одну обёртку из справки установленной версии.
Сокращай обзорный вывод, сохраняя код выхода и существенные предупреждения.
Для доказательства или машинного входа заранее сохрани полный вывод либо первичный артефакт.

## Проверка и результат

Решающий вывод сверяй с первичным артефактом или полным логом по [$fstack:verify](../verify/SKILL.md).
Безопасное чтение можно повторить прямой командой или через документированный RTK bypass.
Не повторяй запись, удаление, миграцию, push или тест с побочными эффектами ради вывода.
Сохраняй видимость отказов и не раскрывай секреты. Укажи существенное ограничение
вывода, а экономию токенов заявляй только по сопоставимому измерению.
