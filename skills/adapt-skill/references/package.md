# Формат и ресурсы навыка

`SKILL.md` начинается с YAML между строками `---`, дальше идут инструкции в
Markdown. Отделяй переносимый метод от настроек конкретного клиента.

| Поле | Требование |
| --- | --- |
| `name` | Совпадает с именем каталога. В fstack от 1 до 64 символов, строчные латинские буквы, цифры и одиночные внутренние дефисы. |
| `description` | От 1 до 1024 символов. Указывает результат и когда нужен навык. |
| `license` | Название лицензии или путь к её файлу в пакете. В fstack обязательна. |
| `compatibility` | От 1 до 500 символов, если задано. Указывает существенные требования к среде. |
| `metadata` | Словарь со строковыми ключами и значениями. |
| `allowed-tools` | Экспериментальное предодобрение инструментов (имена через пробел). Эффект зависит от клиента и может влиять на запросы подтверждения. Поле не заменяет полномочия, выданные пользователем. |

Связывай справки и ресурсы относительными путями. Проверяй, что они доступны
после установки без Git-клона и без предположения о текущем каталоге. Укажи в
`SKILL.md`, когда читать справку или использовать ресурс. Для смены контракта
API или инструмента сверяйся с первоисточником при разработке и закрепляй
устойчивые инструкции локально.

Добавляй скрипт, когда повторяемая операция выигрывает от автоматизации или
ей нужна воспроизводимость. Объяви совместимые версии зависимостей и
неинтерактивные входы. Сделай вывод и ошибки предсказуемыми. Для записи
проверь нужные разрешения, последствия частичного сбоя и повторного запуска.

В fstack добавь новый навык в каталог `docs/skills.md` и согласуй
`agents/openai.yaml`. В `default_prompt` укажи полное имя `$fstack:<name>`.
Автовыбор для нового навыка действует по умолчанию. При переносе сохрани
исходный режим вызова. Например, для режима явного вызова в Claude Code
используется `disable-model-invocation: true`, а в Codex ему соответствует
`policy.allow_implicit_invocation: false` в `agents/openai.yaml`. Проверь
эффект настройки в целевом клиенте. Меняй режим только по поручению.
Для `metadata` используй
`author: WhyFaust` и `source: https://github.com/WhyFaust/fstack`. Версия нового
навыка `1.0.0`. Версию изменённого навыка повышай по его собственному SemVer
одинаково во всех локализациях, пользуясь правилами `docs/development.md`.
