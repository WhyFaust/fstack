# Метаданные навыка Codex

`agents/openai.yaml` читает клиент. Файл необязателен по
[Build skills](https://learn.chatgpt.com/docs/build-skills), но обязателен
в fstack для согласованного UI. Он не заменяет `name`, `description` и
инструкции `SKILL.md`. В `description` оставляй понятную область применения,
а не список ключевых слов или шаблонов для поиска.

## Интерфейс

В `interface` все перечисленные поля имеют строковый тип и необязательны
для Codex. fstack требует `display_name`, `short_description` и `default_prompt`.
Длину текстовых полей считай в символах после свёртки пробельных последовательностей
в один пробел, как в [обработчике клиента](https://github.com/openai/codex/blob/c82708f85803d21fe9046af407107a1ee105b6e5/codex-rs/skills/src/interface.rs).

| Поле | Назначение и ограничение |
| --- | --- |
| `display_name` | Название в UI, от 1 до 64 символов. |
| `short_description` | Краткое описание в UI. Клиент принимает до 1024 символов; правило fstack — 25–64 по рекомендации skill-creator. |
| `default_prompt` | Начальный запрос, до 1024 символов. В fstack содержит полное имя `$fstack:<name>`. Это не системная инструкция и не правило автовыбора. |
| `icon_small`, `icon_large` | Относительные пути к существующим файлам в `assets/` навыка. Для плагина клиент также допускает общий `assets/` пакета. |
| `brand_color` | Цвет вида `#RRGGBB`. |

Добавляй иконки и цвет только для реальной задачи UI. Сохраняй существующие
поля при точечной правке; не заменяй весь YAML генератором, который теряет
`policy` или `dependencies`. Строки лучше заключать в кавычки, особенно
цвет, строки с двоеточием и слова, похожие на логические значения.

В проверенном клиенте точка входа — `agents/openai.yaml`.
`openai_en.yaml` в fstack — сопутствующая локализация, а не подтверждённый
механизм автоматического выбора языка Codex. Проверяй её поля теми же
правилами и сохраняй общую политику и фактические зависимости навыка.

## Вызов

`policy.allow_implicit_invocation` — логическое поле; при отсутствии действует
`true`. Значение `false` скрывает навык из обычного контекста выбора, сохраняя
явный вызов `$skill`. Это подтверждают
[модель метаданных](https://github.com/openai/codex/blob/c82708f85803d21fe9046af407107a1ee105b6e5/codex-rs/skills/src/model.rs)
и [провайдер навыков](https://github.com/openai/codex/blob/c82708f85803d21fe9046af407107a1ee105b6e5/codex-rs/ext/skills/src/provider/host.rs).

Для fstack во всех вариантах UI обязательно значение `false`. В активном
faust-mode исполнитель выбирает метод по смыслу из каталога пакета. Вне режима
пользователь может вызвать отдельный метод явно. Для иного целевого пакета
сохраняй его политику вызова. Разрешение выбора не гарантирует вызов моделью. Имя и описание участвуют в выборе, полный текст читается позже;
коротко называй основной результат и различие с соседними методами в начале
описания, чтобы они сохранились при сокращении каталога клиентом.

## Зависимости инструментов

`dependencies.tools` — список описаний конкретных MCP-серверов, нужных навыку.
Он не перечисляет все возможные инструменты и не выдаёт разрешения на действия.
Не добавляй зависимость для факультативного провайдера с допустимой заменой,
локального CLI или другого навыка. Наличие сервиса в инструкции не подтверждает
его доступность и не разрешает подключение.

По [парсеру метаданных](https://github.com/openai/codex/blob/c82708f85803d21fe9046af407107a1ee105b6e5/codex-rs/skills/src/metadata.rs)
обязательны непустые строки `type` и `value`. Поддерживаемая категория — `mcp`,
`value` задаёт идентификатор сервера. Необязательные `description`, `transport`,
`url` и `command` тоже строки. Лимит `type` и `transport` — 64 символа,
остальных перечисленных полей — 1024 после свёртки пробелов. Описание объясняет,
зачем нужен сервер, но не настраивает его.

В [обработчике MCP-зависимостей](https://github.com/openai/codex/blob/c82708f85803d21fe9046af407107a1ee105b6e5/codex-rs/core/src/mcp_skill_dependencies.rs)
автоматическая установка использует `transport` со значением по умолчанию
`streamable_http` и требует реальный `url`; для `stdio` нужен `command`.
Это не строка shell с произвольными аргументами. Для валидного объявления
достаточно `type` и `value`: отсутствие данных установки не блокирует загрузку
навыка, но обработчик пропускает такую автоустановку с предупреждением.
Сам `value` не доказывает связь с уже настроенным сервером или его доступность;
проверь их в целевой среде. Сложную конфигурацию не выдумывай из сокращённого
объявления. Поля и строки метаданных проверяй отдельно от возможности установки.

В зависимости от клиента, feature и политики объявление может привести
к предложению установить сервер и записи в глобальную конфигурацию Codex.
Не считай его безвредной подписью UI или гарантией установки. Если зависимость
нужна, проверь контракт целевого клиента, настройки и полномочия отдельно.
Сверку структуры, обнаружение клиентом, автовыбор и выполнение навыка
подтверждай раздельно по [критериям проверки](validation.md).
