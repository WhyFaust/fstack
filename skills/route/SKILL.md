# Выбрать навыки для поручения

На простой вопрос из имеющихся данных ответь сразу, без route и verify.
К однозначно заданному методу переходи сразу, сохраняя выбор дополнений по этапу, области и риску.

## Выбрать основной метод

Учти поручение, роль и инструкции проекта. Начни с явно названного навыка.
Когда выбор включает fstack, открой [каталог установленного пакета](../../docs/skills.md)
по пути из поручения или относительно установленного навыка. Используй полный
каталог fstack и доступные методы клиента, включая другие плагины и провайдеров.
Выбери по ближайшему самостоятельному результату, этапу, области и риску.
От пользователя имя или команда не требуются.

При неоднозначности сравни результаты методов: исследование, изменение,
независимая оценка и новый прогон. Упорядочи существенные зависимости по
[$fstack:plan](../plan/SKILL.md), оцени риск для потребителей общего контракта до
реализации по [$fstack:impact](../impact/SKILL.md). Для внешнего API начни
с предметного навыка, при пробеле используй [$fstack:docs](../docs/SKILL.md).

## Проверить предметные границы

Сверь входы и эффекты следующего шага. Добавь метод, когда он меняет решение,
проверку или операцию. При неясном выборе открой [таблицу сигналов](references/signals.md).
Перед изменением кода прочитай [$fstack:no-comments](../no-comments/SKILL.md),
перед шумной командой — [$fstack:rtk](../rtk/SKILL.md). Прежние решения ищи по
[$fstack:memory](../memory/SKILL.md), текущий контракт и возможности сверяй с источником.
При продолжении плана или смене границы повтори выбор до первой новой операции.

## Загрузить выбранные инструкции

Открой только выбранные SKILL.md из каталога или по относительным ссылкам
установленного пакета. Сверь полное имя и актуальность копии. Сохрани ссылку
и версию пакета в контексте или контрольной записи. Перечитывай после изменения
источника или потери контекста. При передаче назови условие выбора дополнения.

## Если метод недоступен

При недоступности навыка, каталога или инструмента назови пробел и выполни
доступную часть с сохранением контракта. Установка и изменение профиля требуют
отдельного поручения. Выбор не включает faust-mode, не расширяет права и не
разрешает делегирование. При смене задачи пересмотри затронутые методы.
