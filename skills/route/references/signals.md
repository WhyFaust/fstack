# Выбор предметного метода

| Условие | Подходящий метод |
| --- | --- |
| Язык, фреймворк или внешний API | Специализированный навык проекта, клиента или плагина. Для Python-контракта используй [$fstack:python](../../python/SKILL.md). Для недостающего API-контракта используй [$fstack:docs](../../docs/SKILL.md). |
| Общий интерфейс и существующие потребители | [$fstack:impact](../../impact/SKILL.md), для перехода потребителей — [$fstack:migrate](../../migrate/SKILL.md) |
| Повтор, транзакция, конкуренция или порядок событий | [$fstack:state](../../state/SKILL.md), для проверки свойства автомата — [$fstack:model-check](../../model-check/SKILL.md) |
| Временная среда, процесс или общий ресурс | [$fstack:resources](../../resources/SKILL.md) |
| Инженерный выбор или интерфейс пользователя | [$fstack:design](../../design/SKILL.md) или [$fstack:ui](../../ui/SKILL.md) по результату этапа |
| Сценарий приёмки, производительность или браузер | [$fstack:verify](../../verify/SKILL.md) для критерия, [$fstack:test](../../test/SKILL.md) для фактического прогона, [$fstack:perf](../../perf/SKILL.md) для измерения, доступный навык браузера для работы с UI |
| Доставка или новый провайдер | Навык площадки и [$fstack:watch-pr](../../watch-pr/SKILL.md) для сопровождения, [$fstack:merge](../../merge/SKILL.md) для разрешённого слияния |

Для задачи с API и конкурентными повторами язык и фреймворк определяют способ работы с API. Атомарность записи и повтор запроса требуют отдельной проверки состояния. При переходе к MR вновь сверь порядок работы площадки.
