# Поиск документации

## Вход и границы

Выдели неизвестную гарантию. При сбое установи фактическую версию процесса
или прогона. В manifest может быть диапазон, в lock-файле — план установки.
Для проектирования возьми поддерживаемый диапазон или заданную версию. Переиспользуй подходящий источник.

## Порядок работы

### Поиск

Убери из запроса секреты, личные данные и закрытый код. С готовым корректным ID
сразу запрашивай документацию.

- MCP: прочитай схемы, вызови `resolve-library-id` / `resolve_library_id`,
  затем `query-docs` / `query_docs`.
- Настроенный [Context7 CLI](https://github.com/upstash/context7/tree/master/packages/cli):
  `ctx7 library "<имя библиотеки>" "<вопрос о контракте>"`, затем
  `ctx7 docs "<ID библиотеки>" "<вопрос о контракте>"`. Опции: `ctx7 --help`.

Выбери ID нужной версии. Обычно достаточно до трёх обращений к каждому
инструменту. При пробеле перейди к официальной документации или исходникам версии.

### Недоступность источника

При недоступности интерфейса используй настроенный CLI или первоисточник.
`ctx7 setup`, `login` и `remove` меняют настройки или авторизацию.
При исчерпании квоты не обходи ограничение сменой транспорта.

## Проверка и результат

Укажи версию, контракт, прямую ссылку и существенные проблемы доступа.
Различай гарантию документации и вывод из исходников. Обозначь непроверенный
факт и его влияние на решение.
