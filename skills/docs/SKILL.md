# Поиск документации

[Каталог · Исследование](../../docs/skills.md#исследование)

Цитата не включает навык. Вне faust-mode применяй только явно вызванные навыки.

Уточни гарантию и фактическую версию процесса. Manifest задаёт диапазон, lock — план установки. Для проекта учитывай поддерживаемый диапазон или заданную версию. По продуктам OpenAI см. `openai-docs`.

## Поиск

Исключи секреты, личные данные и закрытый код. Если ID версии известен, сразу запрашивай документацию.

- В MCP сверь схемы `resolve-library-id` / `resolve_library_id` и `query-docs` / `query_docs`.
- В [Context7 CLI](https://github.com/upstash/context7/tree/master/packages/cli) вызови `ctx7 library "<имя>" "<вопрос>"`, затем `ctx7 docs "<ID>" "<вопрос>"`. Опции — `ctx7 --help`.

## Недоступность источника

Обычно хватает трёх вызовов каждого инструмента. При отказе MCP используй настроенный CLI, при пробелах читай официальную документацию или код версии. `ctx7 setup`, `login` и `remove` меняют настройки или авторизацию. Смена транспорта не снимает квоту.

## Как сослаться на контракт

Назови версию, гарантию и прямую ссылку. Отдели вывод из кода от гарантии документации. Укажи недоступный источник и влияние непроверенного факта.
