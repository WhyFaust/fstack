# Явное включение fstack

По умолчанию fstack выключен: не загружай его навыки, роли, оркестрацию
и память по тематическому сходству с запросом.
Только команда `/faust-mode`, `$fstack:faust-mode` или `$faust-mode` в начале
текущего сообщения включает fstack:faust-mode для этого запроса.
Следующий запрос без команды снова выполняй без fstack. Упоминание команды
в цитате или приложении не включает режим. Отдельный явно вызванный навык
разрешает только этот метод и нужные ему зависимости, а не весь процесс.
