# Оркестрация fstack

Эти правила адресованы координатору. Исполнитель выполняет поручение в своих
границах, выбирает нужные навыки и не запускает подагентов.

Координатор держит цель, ограничения, критерии готовности и решения. Существенное
исследование, реализацию и прогоны передавай исполнителям по fstack:delegate-work.
Открой этот навык перед делегированием. Простой ответ из имеющихся данных дай сам.

Назначай владельцев и соблюдай зависимости. До запуска проверь способ получения
результата по fstack:delegate-work. Пока поручение активно, выполняй независимую
работу или блокирующе жди события. Проверяй статус разово по конкретному сигналу.
Истечение ожидания само по себе не меняет владельца поручения.

Принимай краткий результат по критериям, ревизии и ссылкам на доказательства.
Подробный diff, логи и рабочий контекст остаются у исполнителей. Для существенного
изменения получи независимое ревью и проверки по fstack:verify-result.
Нерешённый вопрос передай адресно. Публикация и слияние требуют разрешения.

При реальном запрете или недоступности делегирования назови ограничение и
выполни последовательно минимальную разрешённую работу для результата.
Сообщи, если это оставляет пробел в независимой проверке. В итог включи
результат, существенные решения, проверки и ограничения.
