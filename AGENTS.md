# fstack

Пиши инструкции навыков и документацию по-русски. Для включения координатора
используй `/faust-mode`, для отключения в этом чате — `/faust-mode-off`.
Агентов и их разрешения предоставляет клиент. Порядок работы описан в
[faust-mode](skills/faust-mode/SKILL.md) и [delegate-work](skills/delegate-work/SKILL.md).

## Навыки и документация

- Один навык даёт один самостоятельный результат. При создании и изменении
  следуй [adapt-skill](skills/adapt-skill/SKILL.md). Вход, порядок действий и
  проверку результата размещай непосредственно в инструкции навыка.
- Формулируй переносимые правила. Настройки и задачи конкретного проекта
  оставляй в этом проекте. При изменении или удалении возможности проверяй
  все упоминания в пакете, включая каталог, подсказки, локализации и схемы.
- Поддерживай [каталог](docs/skills.md) в соответствии с `skills/`. Количество
  навыков вычисляй из пакета. Проверяй пути и ресурсы из установленной копии.
- Сохраняй исходные лицензии и уведомления в `licenses/`. Для внешних
  контрактов сверяй актуальные первичные источники. Личные настройки, токены,
  журналы и данные рабочих проектов хранятся вне репозитория.

## Реализация и выпуск

- Runtime и проверки находятся в `tools/fstack/`. Выражай намерение именами и
  структурой кода. Добавляй минимальные регрессии кода, сохраняй силу проверок.
  Сравнительные эксперименты с моделями запускай только по отдельному запросу.
- Пользователь получает готовый бинарник. При миграции изменяй только файлы
  с подтверждённым владением. Сохраняй пользовательские правки и настройки.
- Перед отправкой выполни [минимальные проверки](docs/development.md#минимальные-проверки).
  Перед слиянием подготовь версию пакета и идентификатор сборки через
  `release prepare`. Версию каждого содержательно изменённого навыка повысь
  отдельно по SemVer во всех локализациях. Несовместимое изменение публичного
  контракта требует major-версии и рабочего перехода для пользователя.
