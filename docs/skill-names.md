# Переименование навыков в fstack 0.3.0

После [обновления пакета](installation.md#переход-с-10x-на-03) замени прежние
имена в командах, инструкциях проектов, шаблонах и сохранённых подсказках.
Вызов нового имени выглядит как `$fstack:why`. Публичные команды
`/faust-mode` и `/faust-mode-off` продолжают работать в привычном виде.
