# Память проекта

## Подключение

Открой существующий vault Obsidian и одобри хуки fstack в настройках Codex.
Начни обычный чат в рабочей папке. Хук найдёт vault и создаст область проекта.
Git worktree одного репозитория используют общую область. Если vault несколько,
выбери рабочий через `memory vault --set PATH`. Для ручного подключения,
восстановления отключённой памяти или выбора имени используй
`memory init --vault PATH --repo PATH --project NAME --mode auto`.

Команды `memory` вызываются через запускатель из установленного пакета.
Запускай их из рабочей папки проекта. В следующих командах укажи
абсолютный путь своего запускателя.

```bash
/bin/sh "$FSTACK_ROOT/launchers/fstack.sh" memory status
```

```powershell
& "$env:FSTACK_ROOT/launchers/fstack.ps1" memory status
```

Убедись, что `status` показывает нужный проект и vault. Сообщи в чате
долговечное правило, затем проверь его применение в новом чате того же проекта.
В Obsidian записи доступны через `Codex Memory/Home.md`. Для ручной проверки
используй `memory search "запрос"` и `memory show ID`.

## Запись и поиск

В режиме `auto` подтверждённые решения и поправки попадают в записи проекта.
Кандидаты для проверки остаются в Inbox. Режим `inbox` отправляет на ручную
проверку все новые записи. Предпочтение становится доступным другим проектам
того же vault по явному указанию пользователя.

Хуки связывают операцию с конкретным ходом. Главный агент готовит её,
`PostToolUse` принимает, а `Stop` применяет. В Plan запись пропускается.
Если заметки нет, проверь доверие к хукам, `memory status` и `memory diagnostics`:
квитанция подготовки и подтверждение записи относятся к разным этапам.
[Работа агента с памятью](../skills/use-memory/SKILL.md).

## Несколько устройств и отключение

Синхронизируй папку `Codex Memory` в Obsidian, включая Markdown, JSON, Bases и
Canvas. На каждом устройстве дождись синхронизации и выполни `memory init` со
своими путями и тем же именем проекта. Заметки общие, привязки и очередь
операций локальны. Перед изменением или удалением записи с другого устройства
дождись доставки предыдущих правок.

Для переноса старого формата обнови fstack на всех устройствах и заверши параллельные правки в vault. Выполни `memory migrate`,
дождись синхронизации и проверь копии во всех проектах. Затем по явному
поручению выполни `memory migrate --prune-legacy`. При расхождении сохрани
обе копии до сверки. `memory disable` выключает автоподключение проекта на
данном устройстве до следующего явного `init`.
