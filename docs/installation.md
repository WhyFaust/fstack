# Установка и обновление

## Через маркетплейс

Нужны Git, Codex с поддержкой плагинов и фоновых хуков и системный `curl`.
Поддерживаются Linux x64 с glibc 2.35+, Windows x64 и macOS на Intel и Apple
Silicon. Зарегистрируй полную ветку, чтобы установить также ресурсы проверки пакета.

```bash
codex plugin marketplace add WhyFaust/fstack --ref main
codex plugin add fstack@fstack --json
```

Одобри хуки в Codex и открой чат. `SessionStart` скачивает бинарник для версии,
идентификатора сборки и платформы, сверяет SHA-256 и сохраняет его в кэше профиля.
Если запрос пришёл до загрузки, повтори его после успешного `SessionStart`.
При сбое проверь журнал хуков. Если выпуск ещё загружается, открой чат позже.
Если этот выпуск успела заменить новая версия, обнови marketplace.

Для автономной установки скачай ZIP своей платформы и соответствующий
`.zip.sha256` из [выпуска](https://github.com/WhyFaust/fstack/releases).
Сверь контрольную сумму и распакуй ZIP в постоянный каталог. Зарегистрируй его
через `codex plugin marketplace add <каталог>`, затем выполни `codex plugin add fstack@fstack`.
Для рабочего клона сначала [собери бинарник](development.md#минимальные-проверки).

## Обновление

Codex с автообновлением Git marketplace получает пакет при старте.
Для явного обновления и проверки выполни:

```bash
codex plugin marketplace upgrade fstack --json
codex plugin list --json
```

Сверь источник, версию и исходное состояние `enabled`. Пустой `upgradedRoots`
при успешном ответе означает, что новый снимок уже получен. Для смены регистрации
с платформенной ветки сохрани её URL, ref и состояние, проверь наличие выпуска
для `main`, затем выполни `codex plugin marketplace remove fstack` и зарегистрируй
`main` командой выше. Для включённого плагина выполни `plugin add` и сверь версию.
У выключенного плагина регистрация обновится сразу, прежняя версия может остаться
в кэше. При следующем включении выполни `codex plugin add fstack@fstack --json`
и сверь `version` и `installedPath` с выбранным выпуском.
При сбое восстанови сохранённую регистрацию. Для ZIP распакуй новый архив
отдельно и переключи регистрацию после проверки.

При обновлении старого профиля фоновый хук убирает только файлы, чьё владение
подтверждено реестром и контрольной суммой. Пользовательские правки сохраняются.
Хук сообщает путь к резервной копии. Если обновление прервётся, следующий запуск
продолжит его с той же копией. При оставшемся PID-файле миграция проверяет,
работает ли прежний помощник. Если владельца установить нельзя, следуй сообщению
о восстановлении. Для предварительного просмотра передай запускателю
`migrate-profile`, а для ручного применения — `migrate-profile --apply`.

## Сверить установленный снимок

Перейди в `installedPath`, который вернул клиент. На Linux или macOS выполни:

```bash
/bin/sh launchers/fstack.sh check-package .
```

На Windows используй PowerShell:

```powershell
& .\launchers\fstack.ps1 check-package .
```

Если требуется подготовить бинарник вручную, используй тот же запускатель
с `--install-runtime` на Unix или `-InstallRuntime` на Windows.

## Удаление

`codex plugin remove fstack@fstack` удаляет плагин. Для удаления регистрации
marketplace отдельно выполни `codex plugin marketplace remove fstack`.
Записи Obsidian и резервные копии профиля сохраняются.
