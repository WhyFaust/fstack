# Каталог навыков

[Исследование](#исследование) · [Планирование](#планирование) · [Реализация](#реализация) · [Проверка](#проверка) ·

В `/faust-mode` выбирай методы перед действием и при смене этапа. В обычном
чате `$fstack:<имя>` вызывает только выбранный навык. [Как выбрать метод](../skills/README.md#как-выбрать-метод).

<a id="исследование-и-выбор-решения"></a>

## Исследование

| Навык | Когда применять |
| --- | --- |
| [how](../skills/how/SKILL.md) | Объяснить путь вызова и данных по текущему коду |
| [why](../skills/why/SKILL.md) | По истории выяснить, зачем приняли решение или когда изменилось поведение |
| [debug](../skills/debug/SKILL.md) | Воспроизвести сбой, установить причину и проверить исправление |
| [audit](../skills/audit/SKILL.md) | Найти и расставить по приоритету проблемы кодовой базы |
| [docs](../skills/docs/SKILL.md) | Уточнить контракт API по документации используемой версии |
