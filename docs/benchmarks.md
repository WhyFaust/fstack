# Бенчмарки fstack

## Нативный runtime

Каждый замер включает старт отдельного процесса, файловый ввод-вывод и проверку
ответа. После одного прогрева p95 считают по ближайшему верхнему рангу. При 11
повторах это максимум. Стоимость холодного запуска измеряй отдельно.

Скрипт собирает release из текущих исходников, создаёт временные профиль и vault
и заполняет их через `memory remember`. Проверяет полный текст записи, поиск
одного совпадения и пустой ответ. Сборка и подготовка корпуса исключены из замеров.

## Повторить измерения

Нужны Python 3.11+, Git и [Rust 1.90.0 с системным toolchain](development.md#минимальные-проверки).

```bash
python tools/fstack/benchmarks/benchmark.py run --output work/benchmark.json --samples 11 --records 256
python tools/fstack/benchmarks/benchmark.py report work/benchmark.json
```

JSON содержит все повторы, параметры, среду и SHA-256 бинарника и исходников.
Сохраняй его вне отслеживаемых файлов. Сравнивай варианты на одной машине
при одинаковом корпусе и нагрузке. Если разница близка к разбросу, повтори серии.
[Оценка работы агента](evaluations.md).
